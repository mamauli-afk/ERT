Латинские термины

CSV данные

Comma-Separated Values — текстовый формат табличных данных, в котором столбцы разделены запятой или точкой с запятой. Удобен для обмена с Excel и другими таблицами, но не хранит типы данных и ограничения. Используется в модуле 8 при экспорте результатов запросов.

См. также: JSON, DDL.

DCL (Data Control Language) SQL

Подмножество SQL для управления правами доступа. Основные команды — GRANT (выдать привилегию) и REVOKE (отозвать). Применяется в модуле 7 при работе с ролями и привилегиями.

См. также: DML, DDL, Привилегия, Роль.

DDL (Data Definition Language) ключевой термин

Data Definition Language — подмножество SQL для определения и изменения структуры базы данных. Основные команды: CREATE, ALTER, DROP. DDL меняет схему (таблицы, индексы, триггеры, процедуры), но не данные внутри таблиц. В Red Expert DDL-скрипты генерируются автоматически из визуального редактора и из ER-диаграмм.

См. также: DML, DCL, ER-диаграмма.

DML (Data Manipulation Language) ключевой термин

Data Manipulation Language — подмножество SQL для работы с данными: SELECT (чтение), INSERT (вставка), UPDATE (обновление), DELETE (удаление). В отличие от DDL, DML не меняет структуру базы данных. Основная часть работы в редакторе SQL-запросов — именно DML.

См. также: DDL, DCL, SQL.

ER-диаграмма ключевой термин

Entity-Relationship diagram — графическое представление структуры базы данных: сущности (таблицы) и связи между ними (1:1, 1:N, N:M). ER-диаграмма помогает спроектировать схему до создания объектов. В Red Expert строится через встроенный построитель — как «с нуля», так и методом reverse engineering.

См. также: Reverse engineering, Сущность, Связь.

Firebird СУБД

Открытая реляционная система управления базами данных с многоверсионной архитектурой. Red Expert изначально создавался как инструмент именно для Firebird; также поддерживает её российский форк — Ред База Данных.

См. также: Ред База Данных, Red Expert, Jaybird.

Jaybird JDBC-драйвер

JDBC-драйвер для Firebird и Ред База Данных. Именно через Jaybird Red Expert подключается к серверу СУБД. Версия драйвера должна соответствовать версии JDK и, в некоторых случаях, версии сервера.

См. также: JDBC, Firebird.

JDBC ключевой термин

Java Database Connectivity — стандартный Java-API для доступа к реляционным СУБД. Программа на Java (в том числе Red Expert) через JDBC-драйвер отправляет SQL-запросы на сервер и получает результаты. Параметры JDBC-подключения (хост, порт, путь к файлу БД, кодировка) задаются в окне создания подключения.

См. также: Jaybird, Red Expert, SQL.

JSON данные

JavaScript Object Notation — текстовый формат обмена данными вида «ключ — значение». В тетради JSON используется как резервная копия ответов: кнопка «Экспорт JSON» сохраняет все введённые ответы и отметки о выполнении в файл.

См. также: CSV.

Red Expert инструмент

Кроссплатформенная GUI-оболочка на Java для администрирования и разработки в Firebird и Ред База Данных. Предоставляет визуальный редактор объектов, SQL-редактор, построитель ER-диаграмм, Trace Manager, менеджеры пользователей и прав.

См. также: Firebird, Ред База Данных, Trace Manager.

Reverse engineering ключевой термин

Обратное проектирование — построение ER-диаграммы по уже существующей базе данных. Инструмент считывает метаданные (таблицы, поля, ключи, связи) и автоматически рисует схему. Обратный процесс — генерация DDL-скрипта из диаграммы.

См. также: ER-диаграмма, DDL.

SQL язык

Structured Query Language — стандартный язык работы с реляционными базами данных. Включает подмножества DDL, DML и DCL. В Red Expert SQL-запросы пишутся в редакторе запросов и выполняются через панель инструментов.

См. также: DDL, DML, DCL.

SSH-туннель сеть

Защищённый канал через SSH, позволяющий подключаться к удалённой СУБД без прямого доступа к её порту в интернете. Параметры SSH-туннеля настраиваются в расширенных настройках подключения Red Expert.

См. также: JDBC.

Trace Manager администрирование

Компонент Red Expert для трассировки действий в базе данных в реальном времени. Позволяет создавать сессии трассировки, фильтровать события и сохранять журнал для анализа.

См. также: Трассировка.

А

Атрибут проектирование

Поле (столбец) сущности или таблицы. На ER-диаграмме атрибуты перечисляются внутри сущности; при создании таблицы каждый атрибут превращается в столбец с типом данных и, при необходимости, ограничениями.

См. также: Сущность, Таблица.

Б

База данных основы

Организованная совокупность данных и метаданных, управляемая СУБД. Физически в Firebird — это файл с расширением .fdb. В Red Expert к одной базе данных может быть открыто несколько подключений, а к разным базам — одновременно.

См. также: СУБД, Firebird.

В

Внешний ключ (FOREIGN KEY) ограничение

Ограничение, обеспечивающее ссылочную целостность: значения в дочерней таблице должны соответствовать значениям первичного ключа в родительской. Пример: STUDENT.GROUP_ID ссылается на GROUP.ID. Нарушение внешнего ключа приводит к ошибке при вставке или удалении.

См. также: Первичный ключ, Таблица.

Г

Генератор объект БД

Объект базы данных, возвращающий уникальные числа по запросу. Используется для автоинкрементных первичных ключей. В Firebird генератор вызывается через GEN_ID(имя_генератора, шаг).

См. также: Первичный ключ, Триггер.

Д

Домен (DOMAIN) объект БД

Именованный пользовательский тип данных с набором ограничений (CHECK, NOT NULL, значение по умолчанию). Позволяет один раз описать типовое поле и переиспользовать его в разных таблицах.

См. также: Таблица.

И

Индекс (INDEX) объект БД

Структура, ускоряющая поиск и сортировку по одному или нескольким столбцам. Создаётся по полям, которые часто используются в WHERE и JOIN. Сравнение стоимости запроса до и после создания индекса — практика модулей 4 и 5.

См. также: Таблица, DDL.

Исключение (EXCEPTION) объект БД

Именованное сообщение об ошибке в PSQL (языке хранимых процедур Firebird). Создаётся один раз и используется в триггерах и процедурах через EXCEPTION и WHEN.

См. также: Триггер, Процедура хранимая.

Н

Нормализация проектирование

Приведение схемы базы данных к нормальным формам (1НФ, 2НФ, 3НФ) для устранения избыточности и аномалий обновления. На практике означает разбиение данных на связанные таблицы вместо хранения всего в одной.

См. также: ER-диаграмма, Сущность.

П

Первичный ключ (PRIMARY KEY) ограничение

Ограничение, однозначно идентифицирующее каждую строку таблицы. Значения первичного ключа уникальны и не могут быть NULL. Обычно используется с генератором для автоинкремента.

См. также: Внешний ключ, Генератор.

Пользователь (USER) администрирование

Учётная запись в СУБД с именем и паролем. Пользователи создаются в менеджере пользователей Red Expert. По умолчанию в Firebird есть встроенный SYSDBA с максимальными правами.

См. также: Привилегия, Роль.

Представление (VIEW) объект БД

Виртуальная таблица, построенная на основе SELECT-запроса. Не хранит данные, а показывает их в удобном виде или ограничивает доступ к части столбцов исходной таблицы.

См. также: Таблица.

Привилегия (PRIVILEGE) администрирование

Право на конкретную операцию с объектом БД: SELECT, INSERT, UPDATE, DELETE, EXECUTE и т.д. Выдаётся пользователю или роли через GRANT и отзывается через REVOKE.

См. также: Роль, DCL.

Процедура хранимая объект БД

Программа на языке PSQL, хранимая в базе данных и вызываемая по имени. Может принимать параметры и возвращать значения (RETURNS). Используется для инкапсуляции логики, которую удобно вызывать из разных мест.

См. также: Триггер, Исключение.

Р

Ред База Данных СУБД

Российская реляционная СУБД на основе Firebird, включённая в реестр отечественного ПО. Red Expert поддерживает её наряду с Firebird.

См. также: Firebird, Red Expert.

Роль (ROLE) администрирование

Именованный набор привилегий. Создаётся один раз, ей выдаются права на объекты, а затем роль назначается нескольким пользователям. Удобно, когда нужно раздать одинаковые права группе учётных записей.

См. также: Привилегия, Пользователь, DCL.

С

Связь проектирование

Отношение между двумя сущностями. Основные типы: «один к одному» (1:1), «один ко многим» (1:N), «многие ко многим» (N:M). На физическом уровне 1:N реализуется через внешний ключ, N:M — через промежуточную таблицу.

См. также: Сущность, Внешний ключ, ER-диаграмма.

СУБД основы

Система управления базами данных — программное обеспечение, которое хранит данные, обрабатывает запросы и обеспечивает целостность и многопользовательский доступ. Примеры: Firebird, Ред База Данных, PostgreSQL, MySQL.

См. также: База данных, Firebird.

Сущность проектирование

Объект предметной области, который на ER-диаграмме изображается прямоугольником, а в базе данных превращается в таблицу. Например: Студент, Группа, Книга.

См. также: Атрибут, Связь, Таблица.

Т

Таблица (TABLE) объект БД

Основная единица хранения данных в реляционной базе: строки и столбцы с заданными типами и ограничениями. Создаётся в Red Expert через визуальный редактор или DDL-скриптом.

См. также: Атрибут, Первичный ключ, Внешний ключ.

Трассировка ключевой термин

Режим мониторинга действий в базе данных в реальном времени: выполняемые SQL-запросы, ошибки, подключения и отключения пользователей. В Red Expert реализована через Trace Manager. Создаёт нагрузку на сервер, поэтому включается на время учебной задачи и выключается после.

См. также: Trace Manager, Пользователь.

Триггер (TRIGGER) объект БД

Процедура на PSQL, автоматически выполняемая при событии INSERT, UPDATE или DELETE. Может срабатывать BEFORE (до изменения строки) или AFTER (после). Типичные применения: авто-заполнение полей, проверка ограничений, ведение истории изменений.

См. также: Процедура хранимая, Генератор, Исключение.
