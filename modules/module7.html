Модуль 7. Администрирование: пользователи, права и трассировка

Цель

Освоить базовые административные функции Red Expert.

Прогресс модуля 0 из 3 (0%)
Краткий теоретический блок

Менеджер пользователей

Инструмент User Manager (менеджер пользователей) предназначен для создания, изменения и удаления учётных записей СУБД. Здесь задаются имя пользователя, пароль, а также административные флаги (например, права SYSDBA).

Менеджер прав

Инструмент Privilege Manager (менеджер прав) управляет тем, что пользователю разрешено делать с объектами базы данных: SELECT, INSERT, UPDATE, DELETE, EXECUTE и т.д. Здесь же назначаются роли — именованные наборы привилегий, которые можно связать с несколькими пользователями.

Роли

Роль — это «пакет» привилегий, который удобно выдавать группе пользователей. Например, роль READER может включать право SELECT на несколько таблиц. Связывание роли с пользователем избавляет от повторной выдачи одних и тех же прав.

Трассировка (Trace Manager)

Trace Manager позволяет в реальном времени отслеживать действия, выполняемые в базе данных: SQL-запросы, ошибки, подключения и отключения пользователей. Журнал трассировки удобно сохранять для отчёта и анализа.

Риски трассировки. Трассировка создаёт нагрузку на сервер и может накапливать большие объёмы данных. Включайте её только на время выполнения учебной задачи и не оставляйте работающей на «боевой» базе без необходимости.
Совет. Разделяйте задачи: учётные записи создаются в менеджере пользователей, а права и роли — в менеджере прав. Так проще не запутаться, кто и что может делать в БД.

Задание 1. Создание пользователя

Создайте нового пользователя TEST_USER с паролем. Предоставьте ему право SELECT только на таблицу STUDENT. Проверьте действие прав, подключившись под новой учётной записью.

Подсказка: в Red Expert откройте Менеджер пользователей (обычно в меню «Инструменты» или через дерево подключения), создайте пользователя, затем в Менеджере прав выдайте SELECT на STUDENT. После — создайте новое подключение под TEST_USER и проверьте, что доступ к другим таблицам закрыт.
Безопасность. Пароль в отчёт не записывается. Укажите только имя пользователя и перечень выданных прав — этого достаточно для проверки задания.

Задание 2. Создание роли

Создайте роль READER, назначьте ей права на чтение нескольких таблиц и свяжите с пользователем TEST_USER.

Подсказка: роль создаётся в Менеджере прав (или через DDL-скрипт CREATE ROLE READER;). Затем роли выдаются привилегии SELECT на нужные таблицы, а сама роль назначается пользователю TEST_USER.

Задание 3. Трассировка

Включите трассировку для отслеживания выполняемых SQL-запросов. Выполните несколько запросов от имени TEST_USER и сохраните журнал трассировки в отчёт.

Подсказка: в Red Expert откройте Trace Manager (или Трассировка в меню «Инструменты»), включите новую сессию трассировки, выполните 3–5 запросов от имени TEST_USER, затем сохраните или скопируйте журнал.
Не забудьте выключить трассировку после выполнения задания — она нагружает сервер и накапливает данные.

  • Понимаю разницу между менеджером пользователей и менеджером прав.

  • Умею проверять действие прав, подключаясь под новой учётной записью.
  • Понимаю, зачем нужны роли и как их назначать.
