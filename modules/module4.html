Модуль 4. Редактор SQL-запросов: базовые и продвинутые возможности

Цель

Научиться писать, форматировать, выполнять и анализировать SQL-запросы.

Прогресс модуля 0 из 4 (0%)
Краткий теоретический блок

Панель инструментов редактора

  • Выполнение запроса — запускает текущий запрос или выделенный фрагмент.
  • Форматирование — автоматически расставляет отступы и переносы, делая запрос читабельным.
  • Автодополнение (обычно Ctrl+Space) — подсказывает имена таблиц, полей и ключевые слова.
  • Комментарии — быстрый способ закомментировать строку или блок (-- и /* ... */).

Панель вывода и вкладка Result Set

  • Result Set — таблица с результатом SELECT: строки, столбцы, типы данных. Здесь удобно просматривать и экспортировать данные.
  • Панель Вывод — служебные сообщения: количество затронутых строк, ошибки, время выполнения, предупреждения.

Параметризованные запросы и история

Параметризованный запрос содержит параметр (например, WHERE CITY = :city), значение которого подставляется при выполнении. Это удобно для многократных запросов с разными значениями. История запросов сохраняет ранее выполненные команды и позволяет быстро к ним возвращаться.

Совет. Для длинных запросов сначала пишите «черновик» в одну строку, затем нажимайте кнопку форматирования — так проще заметить ошибки в структуре JOIN и WHERE.

Задание 1. Простой SELECT

Напишите запрос к таблице учебной БД (например, SELECT * FROM CLIENT). Выполните его и сохраните результат в отчёт.

Подсказка: сначала выполните SELECT * FROM CLIENT, затем усложните запрос — выберите 3–4 конкретных поля и добавьте ORDER BY.

Задание 2. Форматирование и автодополнение

Введите сложный запрос с несколькими JOIN. Используйте кнопку форматирования и автодополнение (Ctrl+Space). Оцените, насколько улучшилась читаемость.

Подсказка: для демонстрации можно взять запрос вида CLIENT JOIN PHONE ON ... JOIN CITY ON ... или аналогичный по вашей учебной БД.

Задание 3. Параметризованный запрос

Создайте запрос с параметром (например, WHERE CITY = :city). Выполните его, подставив разные значения.

Задание 4. Анализ плана запроса продвинутый уровень

Включите отображение плана выполнения и сравните стоимость двух вариантов одного и того же запроса (с индексом и без).
