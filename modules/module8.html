Модуль 8. Импорт, экспорт и выполнение скриптов

Цель

Научиться переносить данные и выполнять пакетные операции.

Прогресс модуля 0 из 3 (0%)
Краткий теоретический блок

Экспорт результатов SELECT-запроса

Результат запроса можно сохранить в разных форматах. Основные из них:

CSV — обмен с таблицами Excel (XLSX) — отчёты SQL-вставки (INSERT) — перенос данных HTML — предпросмотр в браузере JSON — обмен с приложениями XML — интеграция с системами

В Red Expert экспорт обычно доступен из контекстного меню вкладки Result Set или через кнопку на панели результатов.

Выполнение SQL-скриптов из файла

Компонент выполнения скриптов позволяет выбрать SQL-файл и выполнить его целиком или по частям. Это удобно для массовых вставок, развёртывания схемы и переноса данных между базами.

Генерация DDL из метаданных

Red Expert умеет формировать полный DDL-скрипт по существующей базе данных: CREATE TABLE, CREATE INDEX, CREATE TRIGGER, CREATE PROCEDURE и т.д. Такой скрипт — ценный артефакт: его можно сохранить для итогового проекта, резервной копии схемы или переноса БД на другой сервер.

Совет. Перед массовым выполнением скрипта сделайте резервную копию базы данных. Ошибка в одном INSERT может испортить данные, а откатить большие изменения сложно.

Задание 1. Экспорт данных

Выполните запрос к таблице STUDENT и экспортируйте результат в CSV и в SQL-скрипт (INSERT). Сравните форматы.

Подсказка: выполните SELECT * FROM STUDENT;, затем в панели результатов найдите команду экспорта и выберите сначала CSV, затем SQL-вставки. Сохраните оба файла — их содержимое можно скопировать в поля ниже.

Задание 2. Выполнение скрипта

Создайте текстовый файл с несколькими INSERT-запросами для таблицы STUDENT. Выполните его через компонент выполнения скриптов. Проверьте, что данные добавились.

Подсказка: сохраните файл с расширением .sql в кодировке UTF-8. В Red Expert откройте компонент выполнения скриптов, выберите файл и запустите. Затем выполните SELECT * FROM STUDENT; и убедитесь, что новые строки появились.
Важно. Не используйте в INSERT-скрипте ID, которые уже есть в таблице, — это вызовет ошибку нарушения первичного ключа. Возьмите свободные значения или используйте генератор.
  1. Создайте файл inserts.sql с 3–5 INSERT-запросами.
  2. Сохраните его в кодировке UTF-8.
  3. Выполните файл через компонент выполнения скриптов.
  4. Проверьте результат запросом SELECT * FROM STUDENT;.

Задание 3. Генерация DDL

Сгенерируйте полный DDL-скрипт для учебной базы данных. Сохраните его как артефакт для итогового проекта.

Подсказка: в дереве подключений выберите базу данных → Сгенерировать DDL (или Экспорт метаданных в меню инструментов). Сохраните файл .sql — он понадобится в модуле 9.
Артефакт итогового проекта. Этот DDL-скрипт нужно будет приложить к отчёту по модулю 9. Сохраните его в отдельный файл с понятным именем, например ddl_учебная_БД.sql.

Самопроверка по модулю

Отметьте пункты, которые вы уверенно освоили. Если что-то не получается — вернитесь к соответствующему заданию или обратитесь к глоссарию.

  • Умею экспортировать результат SELECT в CSV.
  • Умею экспортировать результат SELECT в SQL-вставки (INSERT).
  • Понимаю, чем отличаются форматы CSV и SQL и когда какой удобнее.
  • Умею выполнять SQL-скрипт из файла через компонент выполнения.
  • Умею проверять результат выполнения скрипта через SELECT.
  • Умею генерировать полный DDL-скрипт из метаданных БД.
  • Сохранил DDL-скрипт как артефакт для итогового проекта.
