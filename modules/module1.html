Что такое Red Expert

Red Expert — это GUI-оболочка на Java для работы с Firebird и Ред База Данных, не зависящая от операционной системы. Благодаря Java инструмент одинаково работает на Windows, Linux и macOS.

Основные возможности

  • визуальный редактор объектов базы данных;
  • SQL-редактор с подсветкой синтаксиса и автодополнением;
  • построение ER-диаграмм и reverse engineering существующей БД;
  • трассировка (Trace Manager) для мониторинга действий в БД;
  • управление пользователями, ролями и правами доступа.

Требования

Наличие JDK: для старых версий Red Expert — не ниже JDK 1.8, для актуальных — JDK 21.

Совет. Перед установкой проверьте версию Java командой java -version в терминале. Если версия ниже требуемой, установите подходящий JDK с сайта разработчика.

Задание 1. Установка и запуск

Установите Red Expert на доступную ОС (Windows/Linux). Запустите приложение и зафиксируйте версию в отчёте.

Задание 2. Первичная настройка

Откройте меню Инструменты → Настройки. Установите русский язык интерфейса (если доступен), проверьте параметры шрифта в редакторе SQL и настройте отображение панели подключений.

Задание 3. Изучение панели инструментов

Соотнесите кнопки на панели инструментов с их горячими клавишами (например, Новый документ — Shift+F12, Сохранить — Ctrl+S).
